# Projects-Codes
This repository contains quantitative codes written during my research and coursework in macroeconomics, macroeconometrics, political economics and public policy.

Main topics:
- Sovereign spreads and debt dynamics
- VAR models for financial shocks
- Macroeconomic time series analysis
- Data construction from FRED, LSEG and financial databases
- Small Open Economy in New Keynesian Framework
- Transition Model for the Italain Pension System

Languages:
- Python
- Matlab
- Dynare
- Excel
